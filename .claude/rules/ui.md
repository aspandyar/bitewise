# UI
- Mobile-first: базовая ширина 375 px, тап-зоны ≥ 44 px, без горизонтального скролла.
- Server Components по умолчанию; "use client" — только где нужен state/эффекты.
- Клиент не считает нутриенты сам — показывает то, что пришло с сервера (или вызывает lib/nutrition через сервер).
- Формы: zod-схема общая с сервером; ошибки — у поля.
- Тексты интерфейса — из lib/i18n/ru.ts, не строками в JSX.
- Пустые состояния, загрузка и ошибка — для каждого экрана.
- Цель скорости: запись приёма пищи ≤ 15 секунд, частые действия ≤ 2 тапа.
