# AI-код
- Модель НЕ возвращает ккал/БЖУ для записи в дневник. Только [{ name, grams, confidence, note }].
- Каждый ответ провайдера — через zod-схему из lib/ai/schemas.ts; невалидный → ошибка, не «починка».
- Ключи только из process.env на сервере; ни одного импорта lib/ai/* из клиентских компонентов.
- Каждый вызов пишет строку в ai_requests (provider, model, tokens, cost, status).
- Дневной лимит запросов на пользователя — из config; превышение → 429.
- Новый провайдер = новый файл, реализующий интерфейс provider.ts. Без `if (provider === …)` по коду.
- Фото: сжатие на клиенте до ~1024 px; по умолчанию не сохранять.
- Тесты — на записанных ответах (fixtures), без реальных вызовов API.
