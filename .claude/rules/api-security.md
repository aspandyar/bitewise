# API и безопасность
- Каждый route handler / server action: проверка сессии первой строкой; без сессии → 401.
- Доступ к объекту — только если его user_id совпадает с сессией (иначе 404, не 403).
- Входные данные — zod; ответ — только нужные поля, без внутренних id других пользователей.
- Rate limit на auth и AI-эндпоинты.
- Никаких секретов в логах и ответах об ошибках.
