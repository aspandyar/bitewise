# Расчёты питания
- Только чистые функции: без БД, без fetch, без Date.now() внутри (дату передавать аргументом).
- Единицы в именах: `grams`, `kcal`, `proteinG`, `per100g`. Никаких безымянных number.
- Хранить и считать без округления; округлять только при отображении (formatKcal, formatGrams).
- Формулы: BMR — Mifflin-St Jeor; TDEE = BMR × activity; коэффициенты — из config.
- Каждая функция — тест с числами, посчитанными вручную, плюс граничные случаи (0 г, рецепт без веса готового блюда).
- Рецепт: нутриенты на 100 г = сумма ингредиентов / cooked_weight_g × 100.
