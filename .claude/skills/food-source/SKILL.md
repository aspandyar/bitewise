3. Нет ккал, но есть БЖУ → kcal = 4×Б + 9×Ж + 4×У с пометкой; нет ничего → не импортировать.
4. Кэшируй в foods (по barcode / external_id); повторный запрос — из базы.
5. Атрибуция: Open Food Facts — лицензия ODbL, указать источник в UI карточки продукта.
6. Тесты на fixtures реальных ответов (сохранить в tests/fixtures/<source>/).
