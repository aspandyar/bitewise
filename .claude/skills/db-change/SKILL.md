---
name: db-change
description: Изменить схему БД безопасно — schema.ts, генерация миграции, показ SQL, применение, тесты. Использовать при любом изменении таблиц, колонок или индексов.
---
1. Опиши изменение и зачем оно нужно; проверь rules/db.md.
2. Измени db/schema.ts.
3. `pnpm db:generate`. Покажи мне сгенерированный SQL целиком.
4. Отметь риски: потеря данных, блокировка большой таблицы, NOT NULL без default.
5. После моего «ок» — `pnpm db:migrate` на dev-базе.
6. Обнови типы/репозитории, прогони `pnpm test`.
7. Обнови модель данных в docs/architecture.md.
