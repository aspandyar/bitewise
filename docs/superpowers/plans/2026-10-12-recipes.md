# Этап 4 — блюда: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пользователь собирает своё блюдо из продуктов (граммами или порциями), указывает вес готового блюда и число порций и добавляет блюдо в дневник одной записью, как обычный продукт.

**Architecture:** Блюдо — это строка `foods` (`source = 'user'`, владелец) плюс строка `recipes` и строки `recipe_items`. Цифры на 100 г считает `calcRecipe` в `lib/nutrition.ts`, а `lib/recipes/recompute.ts` записывает их в строку `foods` блюда и ведёт его единственную порцию «1 порция». Пересчёт идёт при каждом изменении блюда, при правке своего продукта-ингредиента и при сиде. Поиск, экран количества и `diary_entries` работают без изменений. Продукты знают о блюдах через `isRecipe` (EXISTS) и не дают править блюдо как продукт.

**Tech Stack:** Next.js 16 (App Router, `cacheComponents`), React 19, TypeScript strict, Drizzle ORM 0.45 + Postgres 17, zod 4, Vitest 5, Tailwind v4.

**Spec:** `docs/superpowers/specs/2026-10-12-recipes-design.md`

## Global Constraints
- Нутриенты считает только `lib/nutrition.ts`; клиент нутриенты не считает (ккал приходят с серверной страницы).
- Без магических чисел: всё настраиваемое — в `lib/config.ts`.
- Комментарии в коде — по-английски, объясняют «почему». Тексты интерфейса — только из `lib/i18n/ru.ts`.
- Каждый запрос к `recipes` / `recipe_items` фильтрует по `user_id` сессии; чужое или удалённое → «не найдено» (404).
- Схема БД — только в `db/schema.ts`, миграция через `/db-change` (`pnpm db:generate` → показать SQL → «ок» → `pnpm db:migrate`); сгенерированный SQL не править.
- Хранить и считать без округления; округлять только при выводе (`lib/format.ts`). Исключение — сравнение веса с границей (до сотых, см. Task 1).
- Mobile-first 375 px, тап-зоны ≥ 44 px (`min-h-11`), без горизонтального скролла.
- Каждая страница — `<Suspense fallback={<PageLoading />}>` + `…Content`, сессия читается внутри.
- Клиентская форма или поиск на странице, куда возвращаются по ссылке, получает `key` из входных данных (`ui.md`).
- `RECIPE_LIMITS`: до 50 ингредиентов; вес готового блюда 0,1–20 000 г; порций 1–100 (целое). Граммы и количество порций ингредиента — `DIARY_LIMITS.grams` (0,1–5000) и `DIARY_LIMITS.portionCount` (0,25–50). Блюда входят в `FOOD_LIMITS.maxOwnFoods` (1000).
- Новых зависимостей нет.
- Коммиты — Conventional Commits по-английски, в конце `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Не пушить.

## Review Focus
- **Drizzle не квалифицирует колонки в запросе к одной таблице** (`select "id", EXISTS (SELECT 1 FROM "recipes" WHERE "food_id" = "id") from "foods"` — оба `id` станут `recipes.id`). Подзапрос `isRecipe` пишется явным SQL `"recipes"."food_id" = "foods"."id"`. Тест — Task 4: в выдаче поиска `isRecipe` true только у блюда.
- **Шум float**: продукт 33,3 + 33,3 + 33,4 г БЖУ на 100 г, 100 г без веса готового → граница веса не должна сработать (`weightRaised = false`). Тест — Task 1.
- **Продукт «только ккал»** (900 ккал, БЖУ 0) и вес готового 1 г → без границы по ккал 90 000 ккал на 100 г; граница по ккал держит ≤ 900. Тест — Task 1.
- **Крошечная порция**: вес 0,1 г на 100 порций → 0,001 г округлится в `numeric(8,2)` до 0 и нарушит CHECK порции → порция не создаётся. Тест — Task 5.
- **Удаление пользователя**, у которого блюдо из своих продуктов: FK `recipe_items.food_id` (no action) не должен блокировать каскад. Тест — Task 5.

```ts
export type RecipeItemValues = { per100g: Per100g; grams: number };

export type RecipeTotals = {
  rawWeightG: number;
  // What the totals are divided by: the cooked (or raw) weight, never below what is plausible.
  weightG: number;
  totals: Nutrients;
  per100g: Per100g;
  weightRaised: boolean;
};

const ZERO_PER_100G: Per100g = { kcal100: 0, protein100: 0, fat100: 0, carbs100: 0 };
const STORAGE_SCALE = 10 ** NUTRIENT_STORAGE_DECIMALS;

// A dish cannot weigh less than its protein, fat and carbs, nor hold more kcal per 100 g than any
// food may. Rounded to stored precision so float noise (33.3 + 33.3 + 33.4) never flags an honest
// raw weight.
function minPlausibleWeightG(totals: Nutrients): number {
  const byNutrients =
    ((totals.proteinG + totals.fatG + totals.carbsG) * NUTRIENT_BASE_GRAMS) /
    FOOD_LIMITS.maxTotalGramsPer100G;
  const byKcal = (totals.kcal * NUTRIENT_BASE_GRAMS) / FOOD_LIMITS.kcal100.max;
  return Math.round(Math.max(byNutrients, byKcal) * STORAGE_SCALE) / STORAGE_SCALE;
}

// Water boils off, so a dish is divided by its cooked weight; without one, by the raw weight.
export function calcRecipe(
  items: readonly RecipeItemValues[],
  cookedWeightG: number | null,
): RecipeTotals {
  if (cookedWeightG !== null) assertPositive("cookedWeightG", cookedWeightG);
  const totals = sumNutrients(items.map((item) => calcEntryNutrients(item.per100g, item.grams)));
  const rawWeightG = items.reduce((sum, item) => sum + item.grams, 0);
  const statedWeightG = cookedWeightG ?? rawWeightG;
  // A typo ("10 g" for a pot) or a later edit of an ingredient must not yield 4000 kcal per 100 g
  // or overflow numeric(8,2); forms reject such weights, this keeps stored numbers possible.
  const weightG = Math.max(statedWeightG, minPlausibleWeightG(totals));
  const per100 = (value: number) => (value * NUTRIENT_BASE_GRAMS) / weightG;
  return {
    rawWeightG,
    weightG,
    totals,
    per100g:
      weightG > 0
        ? {
            kcal100: per100(totals.kcal),
            protein100: per100(totals.proteinG),
            fat100: per100(totals.fatG),
            carbs100: per100(totals.carbsG),
          }
        : ZERO_PER_100G,
    weightRaised: weightG > statedWeightG,
  };
}

export function calcServingGrams(weightG: number, servings: number): number {
  assertNonNegative("weightG", weightG);
  assertPositive("servings", servings);
  return weightG / servings;
}
```

// Diary entries and recipe ingredients store the same amount: grams, or a portion snapshot × count.
// Kept free of DB imports so client components can use these types.
export type GramsAmount = { mode: "grams"; grams: number };

export type AddAmount = GramsAmount | { mode: "portion"; portionId: string; count: number };

// Editing keeps the portion snapshot: only its count changes, or the amount switches to grams.
export type UpdateAmount = GramsAmount | { mode: "portion"; count: number };

const STORAGE_SCALE = 10 ** NUTRIENT_STORAGE_DECIMALS;
// Inputs get the precision the columns store, so grams = count × portion grams holds once saved.
export const toStoragePrecision = (value: number) =>
  Math.round(value * STORAGE_SCALE) / STORAGE_SCALE;

const { grams, portionCount } = DIARY_LIMITS;
const gramsField = () =>
  decimalField(grams, ru.errors.gramsRange(grams.min, grams.max)).transform(toStoragePrecision);
const countField = () =>
  decimalField(portionCount, ru.errors.portionCount(portionCount.min, portionCount.max)).transform(
    toStoragePrecision,
  );

const gramsAmountSchema = z.object({ mode: z.literal("grams"), grams: gramsField() });

export const addAmountSchema = z.discriminatedUnion("mode", [
  gramsAmountSchema,
  z.object({
    mode: z.literal("portion"),
    portionId: z.uuid({ error: ru.errors.choosePortion }),
    count: countField(),
  }),
]);

export const updateAmountSchema = z.discriminatedUnion("mode", [
  gramsAmountSchema,
  z.object({ mode: z.literal("portion"), count: countField() }),
]);

export type AddAmountForm = z.infer<typeof addAmountSchema>;
export type UpdateAmountForm = z.infer<typeof updateAmountSchema>;

export function toAddAmount(form: AddAmountForm): AddAmount {
  return form.mode === "grams"
    ? { mode: "grams", grams: form.grams }
    : { mode: "portion", portionId: form.portionId, count: form.count };
}

export function toUpdateAmount(form: UpdateAmountForm): UpdateAmount {
  return form.mode === "grams"
    ? { mode: "grams", grams: form.grams }
    : { mode: "portion", count: form.count };
}

export type AmountColumns = {
  grams: number;
  portionLabel: string | null;
  portionGrams: number | null;
  portionCount: number | null;
};

export const NO_PORTION = { portionLabel: null, portionGrams: null, portionCount: null } as const;

export function toAmountColumns(amount: AddAmount, portion: PortionValues | null): AmountColumns {
  if (amount.mode === "grams") return { grams: amount.grams, ...NO_PORTION };
  // Callers look the portion up first and answer "not found" when it is missing.
  if (!portion) throw new Error("portion amount without a portion");
  return {
    grams: calcPortionGrams(portion.grams, amount.count),
    portionLabel: portion.label,
    portionGrams: portion.grams,
    portionCount: amount.count,
  };
}

export function optionalIntegerField(limits: { min: number; max: number }, message: string) {
  return z.preprocess(
    (value) => {
      if (typeof value !== "string") return value;
      const trimmed = value.trim();
      return trimmed === "" ? null : trimmed;
    },
    z.coerce
      .number({ error: message })
      .int({ error: message })
      .min(limits.min, { error: message })
      .max(limits.max, { error: message })
      .nullable(),
  );

import { z } from "zod";
// …
// Ingredient pickers hide recipes: a dish inside a dish is not supported.
const excludeSchema = z.literal("recipes").nullable();

export async function handleFoodSearch(
  input: { userId: string | null; rawQuery: string | null; rawExclude?: string | null; nowMs: number },
  deps: {
    limiter: RateLimiter;
    search: (
      userId: string,
      query: string,
      options: { excludeRecipes: boolean },
    ) => Promise<FoodListItem[]>;
  },
): Promise<FoodSearchResponse> {
  // … 401, 429 как было
  const query = normalizeFoodQuery(input.rawQuery);
  const exclude = excludeSchema.safeParse(input.rawExclude ?? null);
  if (!query || !exclude.success) return { status: 400, body: { error: "bad_query" } };
  try {
    const items = await deps.search(input.userId, query, {
      excludeRecipes: exclude.data === "recipes",
    });
    return { status: 200, body: { items } };
  } catch (error) { /* как было */ }
}

import { eq, inArray, sql } from "drizzle-orm";
import { foodPortions, foods, recipeItems, recipes } from "@/db/schema";
import type { Db } from "@/db/types";
import { PORTION_LIMITS } from "@/lib/config";
import { ru } from "@/lib/i18n/ru";
import { calcRecipe, calcServingGrams, type RecipeItemValues } from "@/lib/nutrition";

export const per100gColumns = {
  kcal100: foods.kcal100,
  protein100: foods.protein100,
  fat100: foods.fat100,
  carbs100: foods.carbs100,
};

// Deleted foods are read too: an ingredient deleted later keeps counting with its numbers.
export async function loadRecipeItemValues(
  db: Db,
  recipeId: string,
): Promise<(RecipeItemValues & { id: string })[]> {
  return db
    .select({ id: recipeItems.id, grams: recipeItems.grams, per100g: per100gColumns })
    .from(recipeItems)
    .innerJoin(foods, eq(foods.id, recipeItems.foodId))
    .where(eq(recipeItems.recipeId, recipeId));
}

type ServingTarget = { foodId: string; userId: string; servings: number | null };

// addPortion refuses recipe foods, so the only portion a recipe food has is its serving.
async function syncServingPortion(db: Db, recipe: ServingTarget, weightG: number): Promise<void> {
  const grams = recipe.servings === null ? null : calcServingGrams(weightG, recipe.servings);
  const [current] = await db
    .select({ id: foodPortions.id })
    .from(foodPortions)
    .where(eq(foodPortions.foodId, recipe.foodId))
    .limit(1);
  // A serving below the smallest portion would round to 0 g in numeric(8,2).
  if (grams === null || grams < PORTION_LIMITS.grams.min) {
    if (current) await db.delete(foodPortions).where(eq(foodPortions.foodId, recipe.foodId));
    return;
  }
  if (current) {
    await db.update(foodPortions).set({ grams }).where(eq(foodPortions.id, current.id));
  } else {
    await db.insert(foodPortions).values({
      foodId: recipe.foodId,
      userId: recipe.userId,
      label: ru.recipes.servingLabel,
      grams,
    });
  }
}

// Stores what calcRecipe says into the recipe's food row, so search and the diary read it as is.
export async function recomputeRecipe(db: Db, recipeId: string): Promise<void> {
  const [recipe] = await db
    .select({
      foodId: recipes.foodId,
      userId: recipes.userId,
      cookedWeightG: recipes.cookedWeightG,
      servings: recipes.servings,
    })
    .from(recipes)
    .where(eq(recipes.id, recipeId))
    .limit(1);
  if (!recipe) throw new Error(`recipe ${recipeId} not found`);
  const result = calcRecipe(await loadRecipeItemValues(db, recipeId), recipe.cookedWeightG);
  await db
    .update(foods)
    .set({ ...result.per100g, fiber100: null, updatedAt: sql`now()` })
    .where(eq(foods.id, recipe.foodId));
  await syncServingPortion(db, recipe, result.weightG);
}

export async function recomputeRecipesUsingFoods(
  db: Db,
  foodIds: readonly string[],
): Promise<number> {
  if (foodIds.length === 0) return 0;
  const rows = await db
    .selectDistinct({ recipeId: recipeItems.recipeId })
    .from(recipeItems)
    .where(inArray(recipeItems.foodId, [...foodIds]));
  for (const { recipeId } of rows) await recomputeRecipe(db, recipeId);
  return rows.length;
}

import { foodPortions, foods, recipeItems, recipes } from "@/db/schema";
import type { Db } from "@/db/types";
import { NO_PORTION, toAmountColumns, type AddAmount, type UpdateAmount } from "@/lib/amount";
import { RECIPE_LIMITS } from "@/lib/config";

import type { PortionValues } from "@/lib/foods/types";

import type {
  RecipeDetails,
  RecipeListItem,
  RecipeValues,
  RecipeWriteResult,

// A recipe lives while its food row does: deleting a recipe soft-deletes that row.
function ownLiveRecipe(userId: string, recipeId: string) {
  return and(eq(recipes.id, recipeId), eq(recipes.userId, userId), isNull(foods.deletedAt));
}

// A stated weight must stay plausible for the composition; without one the raw weight always is.
function weightTooLow(items: readonly RecipeItemValues[], cookedWeightG: number | null): boolean {
  return cookedWeightG !== null && calcRecipe(items, cookedWeightG).weightRaised;
}

// Serializes writes to one recipe, so parallel adds cannot pass the item cap or store numbers
// computed from a composition another request has just changed.
async function lockOwnRecipe(tx: Db, userId: string, recipeId: string) {
  await tx.execute(sql`SELECT pg_advisory_xact_lock(hashtext(${recipeId}))`);
  const [recipe] = await tx
    .select({ foodId: recipes.foodId, cookedWeightG: recipes.cookedWeightG })
    .from(recipes)
    .innerJoin(foods, eq(foods.id, recipes.foodId))
    .where(ownLiveRecipe(userId, recipeId))
    .limit(1);
  return recipe ?? null;
}

export async function countRecipes(db: Db, userId: string): Promise<number> {
  const [row] = await db
    .select({ total: count() })
    .from(recipes)
    .innerJoin(foods, eq(foods.id, recipes.foodId))
    .where(and(eq(recipes.userId, userId), isNull(foods.deletedAt)));
  return row?.total ?? 0;
}

export async function getRecipe(
  db: Db,
  userId: string,
  recipeId: string,

  const [recipe] = await db

      id: recipes.id,

      name: foods.name,
      cookedWeightG: recipes.cookedWeightG,
      servings: recipes.servings,

    .from(recipes)
    .innerJoin(foods, eq(foods.id, recipes.foodId))

export async function updateRecipe(
  db: Db,
  userId: string,
  recipeId: string,
  values: RecipeValues,
): Promise<"ok" | "not_found" | "weight_too_low"> {
  return db.transaction(async (tx) => {
    const recipe = await lockOwnRecipe(tx, userId, recipeId);
    if (!recipe) return "not_found";
    if (weightTooLow(await loadRecipeItemValues(tx, recipeId), values.cookedWeightG)) {
      return "weight_too_low";
    }
    await tx
      .update(foods)
      .set({ name: values.name, updatedAt: sql`now()` })
      .where(eq(foods.id, recipe.foodId));
    await tx
      .update(recipes)
      .set({ cookedWeightG: values.cookedWeightG, servings: values.servings, updatedAt: sql`now()` })
      .where(eq(recipes.id, recipeId));
    await recomputeRecipe(tx, recipeId);
    return "ok";
  });
}

export async function deleteRecipe(db: Db, userId: string, recipeId: string): Promise<boolean> {
  return db.transaction(async (tx) => {
    const recipe = await lockOwnRecipe(tx, userId, recipeId);
    if (!recipe) return false;
    // Soft delete: diary entries keep pointing at the recipe's food.
    await tx
      .update(foods)
      .set({ deletedAt: sql`now()`, updatedAt: sql`now()` })
      .where(eq(foods.id, recipe.foodId));
    return true;
  });
}

export async function addItem(
  db: Db,
  userId: string,
  recipeId: string,
  input: { foodId: string; amount: AddAmount },
  // Injectable so tests can reach the cap without inserting fifty rows.
  limits: { maxItems: number } = RECIPE_LIMITS,
): Promise<RecipeWriteResult> {
  return db.transaction(async (tx) => {
    const recipe = await lockOwnRecipe(tx, userId, recipeId);
    if (!recipe) return "not_found";
    // Not a recipe: dishes inside dishes are not supported, which also rules out cycles.
    const [food] = await tx
      .select(per100gColumns)
      .from(foods)
      .where(and(eq(foods.id, input.foodId), visibleTo(userId), notRecipe))
      .limit(1);
    if (!food) return "not_found";
    let portion: PortionValues | null = null;
    if (input.amount.mode === "portion") {
      portion = await getVisiblePortion(tx, userId, input.foodId, input.amount.portionId);
      if (!portion) return "not_found";
    }
    const items = await loadRecipeItemValues(tx, recipeId);
    if (items.length >= limits.maxItems) return "limit";
    const columns = toAmountColumns(input.amount, portion);
    if (weightTooLow([...items, { per100g: food, grams: columns.grams }], recipe.cookedWeightG)) {
      return "weight_too_low";
    }
    await tx.insert(recipeItems).values({ recipeId, userId, foodId: input.foodId, ...columns });
    await recomputeRecipe(tx, recipeId);
    return "ok";
  });
}

export async function updateItem(
  db: Db,
  userId: string,
  recipeId: string,
  itemId: string,
  amount: UpdateAmount,
): Promise<"ok" | "not_found" | "weight_too_low"> {
  return db.transaction(async (tx) => {
    const recipe = await lockOwnRecipe(tx, userId, recipeId);
    if (!recipe) return "not_found";
    const [item] = await tx
      .select({ portionGrams: recipeItems.portionGrams })
      .from(recipeItems)
      .where(and(eq(recipeItems.id, itemId), eq(recipeItems.recipeId, recipeId)))
      .limit(1);
    if (!item) return "not_found";
    // Only the snapshotted portion can be counted; a grams ingredient has none to count.
    if (amount.mode === "portion" && item.portionGrams === null) return "not_found";
    const grams =
      amount.mode === "grams"
        ? amount.grams
        : calcPortionGrams(item.portionGrams ?? 0, amount.count);
    const items = (await loadRecipeItemValues(tx, recipeId)).map((current) =>
      current.id === itemId ? { ...current, grams } : current,
    );
    if (weightTooLow(items, recipe.cookedWeightG)) return "weight_too_low";
    await tx
      .update(recipeItems)
      .set(
        amount.mode === "grams"
          ? { grams, ...NO_PORTION }
          : { grams, portionCount: amount.count },
      )
      .where(eq(recipeItems.id, itemId));
    await recomputeRecipe(tx, recipeId);
    return "ok";
  });
}

export async function deleteItem(
  db: Db,
  userId: string,
  recipeId: string,
  itemId: string,
): Promise<boolean> {
  return db.transaction(async (tx) => {
    const recipe = await lockOwnRecipe(tx, userId, recipeId);
    if (!recipe) return false;
    const rows = await tx
      .delete(recipeItems)
      .where(and(eq(recipeItems.id, itemId), eq(recipeItems.recipeId, recipeId)))
      .returning({ id: recipeItems.id });
    if (rows.length === 0) return false;
    await recomputeRecipe(tx, recipeId);
    return true;
  });
}

  if (!parsed.success) return { fieldErrors: firstFieldErrors(parsed.error) };
  const result = await addItem(db, userId, id, { foodId: food, amount: toAddAmount(parsed.data) });
  if (result !== "ok") return itemFailure(result);
  redirect(recipeHref(id));
}

export async function updateItemAction(
  recipeId: string,
  itemId: string,
  _prev: FormState,
  formData: FormData,
): Promise<FormState> {
  const userId = await requireUserId();
  const id = requireId(recipeId);
  const item = requireId(itemId);
  const parsed = updateAmountSchema.safeParse(Object.fromEntries(formData));
  if (!parsed.success) return { fieldErrors: firstFieldErrors(parsed.error) };
  const result = await updateItem(db, userId, id, item, toUpdateAmount(parsed.data));
  if (result !== "ok") return itemFailure(result);
  redirect(recipeHref(id));
}

export async function deleteItemAction(recipeId: string, itemId: string): Promise<void> {
  const userId = await requireUserId();
  const id = requireId(recipeId);
  if (!(await deleteItem(db, userId, id, requireId(itemId)))) notFound();
  redirect(recipeHref(id));
}

  params,

  const recipeId = parseId(raw.id);
  const foodId = parseId(raw.foodId);
  if (!recipeId || !foodId) notFound();
  const [recipe, food, portions] = await Promise.all([
    getRecipe(db, userId, recipeId),
    getVisibleFood(db, userId, foodId),
    listVisiblePortions(db, userId, foodId),
  ]);
  // A dish inside a dish is not supported; the server action refuses it too.
  if (!recipe || !food || food.isRecipe) notFound();
  const options: PortionOption[] = portions.map((portion) => ({
    id: portion.id,
    label: portion.label,
    grams: portion.grams,
    kcal: calcEntryNutrients(food, portion.grams).kcal,
  }));
  return (
    <main className="mx-auto flex w-full max-w-md flex-1 flex-col gap-4 px-4 py-8">
      <BackLink href={ingredientSearchHref(recipe.id)} />

        <h1 className="text-2xl font-semibold [overflow-wrap:anywhere]">{food.name}</h1>
        <p className="text-foreground/60">{ru.diary.kcalPer100g(formatKcal(food.kcal100))}</p>

        key={`${recipe.id}:${food.id}:${recipe.items.length}`}

}

import { ConfirmDeleteButton } from "@/components/ui/confirm-delete-button";

import { requireUserId } from "@/lib/auth/session";
import { DIARY_LIMITS } from "@/lib/config";

import { parseId } from "@/lib/ids";
import { calcEntryNutrients } from "@/lib/nutrition";
import { recipeHref } from "@/lib/recipes/paths";

async function EditIngredientContent({
  params,
}: Pick<PageProps<"/recipes/[id]/items/[itemId]/edit">, "params">) {
  const userId = await requireUserId();
  const raw = await params;
  const recipeId = parseId(raw.id);
  const itemId = parseId(raw.itemId);
  if (!recipeId || !itemId) notFound();
  const recipe = await getRecipe(db, userId, recipeId);
  const item = recipe?.items.find((candidate) => candidate.id === itemId);
  if (!recipe || !item) notFound();

  const portion: PortionOption | null =
    item.portionLabel !== null && item.portionGrams !== null
      ? {
          id: null,
          label: item.portionLabel,
          grams: item.portionGrams,
          kcal: calcEntryNutrients(item.per100g, item.portionGrams).kcal,
        }
      : null;
  const initial: AmountInitial = {
    mode: portion && item.portionCount !== null ? "portion" : "grams",
    portionIndex: 0,
    count: item.portionCount ?? DIARY_LIMITS.portionCount.default,
    grams: item.grams,
  };

  return (
    <main className="mx-auto flex w-full max-w-md flex-1 flex-col gap-4 px-4 py-8">
      <BackLink href={recipeHref(recipe.id)} />
      <div className="flex flex-col gap-1">
        <p className="text-sm text-foreground/60">{ru.recipes.editIngredientTitle}</p>
        <h1 className="text-2xl font-semibold [overflow-wrap:anywhere]">{item.foodName}</h1>
      </div>
      {/* Keyed by the stored values so a revisit after saving never re-saves the old amount. */}
      <ItemAmountForm
        key={`${item.id}:${item.grams}:${item.portionCount}`}
        action={updateItemAction.bind(null, recipe.id, item.id)}
        portions={portion ? [portion] : []}
        initial={initial}
        submitLabel={ru.common.save}
      />
      <ConfirmDeleteButton action={deleteItemAction.bind(null, recipe.id, item.id)} />
    </main>
  );
}

export default function EditIngredientPage({
  params,
}: PageProps<"/recipes/[id]/items/[itemId]/edit">) {
  return (
    <Suspense fallback={<PageLoading />}>
      <EditIngredientContent params={params} />
    </Suspense>
  );
}
