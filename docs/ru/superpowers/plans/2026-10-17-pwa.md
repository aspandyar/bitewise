# Этап 6а — `ft/pwa`: план реализации

> **Для исполнителя:** обязательный навык — superpowers:executing-plans (или superpowers:subagent-driven-development). Шаги — чекбоксы `- [ ]`.

**Цель:** тема и акцентный цвет на выбор (cookie, без мигания), экран «Оформление», manifest и иконки, service worker со страницей «Нет сети», плашка `useOffline`, строка «Установить на телефон».

**Архитектура:** вся палитра и правила — в `lib/config.ts` (`APPEARANCE`, `PWA`); чистые функции в `lib/appearance.ts` собирают CSS-переменные тем и текст inline-скрипта, который до первой отрисовки ставит `data-theme` / `data-accent` на `<html>`; корневой layout cookie на сервере не читает. Service worker, офлайн-страница и PNG-иконки отдаются route handlers, собранными из config и `ru.ts`, — без файлов, которые надо держать в согласии руками.

**Стек:** Next.js 16 (App Router, cacheComponents, `next/og`, `experimental.useOffline`), React 19, TypeScript strict, zod 4, Vitest, Tailwind v4.

**Спека:** `docs/superpowers/specs/2026-10-17-pwa-design.md`

## Глобальные ограничения
- Все значения — в `lib/config.ts`: `THEMES`, `ACCENTS`, `APPEARANCE` (cookie `theme`/`accent`, год, `minContrast = 4.5`, палитра), `PWA` (размеры иконок 192/512, apple 180, favicon 32, `maskableScale`, пути, `cacheName`).
- Тексты — из `lib/i18n/ru.ts`, включая офлайн-страницу и manifest.
- Корневой layout не вызывает `cookies()`; cookie читает только экран «Оформление» внутри `<Suspense>`.
- Значения из cookie и из браузера — только через списки/zod; неизвестное → значение по умолчанию.
- Каждый server action — `requireUserId()` первой строкой.
- 375 px, тап-зоны ≥ 44 px; клиентская форма на экране, куда возвращаются по ссылке, — `key` из входных данных.
- Без новых зависимостей; БД и миграции не меняются.
- Коммиты — Conventional Commits, без строк атрибуции. Ветка `ft/pwa`, основная — `master`.

## На что смотреть при ревью
1. Подделанная cookie (`theme=dark"><script>`, `accent=red`, пусто, повтор имени) — атрибут не ставится, вид по умолчанию (тесты в задаче 1).
2. Система тёмная, выбрана «Светлая» (и наоборот) с цветным акцентом — цвета выбранной темы, акцент своего оттенка (порядок правил — тест в задаче 1, вид — ui-checker в задаче 9).
3. После деплоя с новым `cacheName` старый кэш service worker удаляется, офлайн-страница — новая (тест в задаче 6).
4. Без сети запросы данных, server actions и JS не перехватываются service worker — только навигации (тест в задаче 6); отправка формы при обрыве уходит один раз после восстановления (ui-checker в задаче 9).
5. Строка установки не даёт расхождения гидрации: сервер и первый клиентский рендер — пусто, подсказка — после монтирования (тест `installHint` в задаче 8, консоль — ui-checker).

```ts
import { z } from "zod";
import { ACCENTS, APPEARANCE, THEMES, type Accent, type Theme } from "@/lib/config";

export type Appearance = { theme: Theme; accent: Accent };
type ColorMode = "light" | "dark";

export const themeSchema = z.enum(THEMES);
export const accentSchema = z.enum(ACCENTS);
export const appearanceSchema = z.object({ theme: themeSchema, accent: accentSchema });

// Cookies are client-controlled: anything outside the lists means "not chosen".
export function parseAppearance(raw: { theme?: string; accent?: string }): Appearance {
  const theme = themeSchema.safeParse(raw.theme);
  const accent = accentSchema.safeParse(raw.accent);
  return {
    theme: theme.success ? theme.data : APPEARANCE.defaults.theme,
    accent: accent.success ? accent.data : APPEARANCE.defaults.accent,
  };
}

export function readAppearanceCookie(documentCookie: string): Appearance {
  const values = new Map(
    documentCookie.split("; ").map((item) => {
      const at = item.indexOf("=");
      return [item.slice(0, at), item.slice(at + 1)] as const;
    }),
  );
  return parseAppearance({
    theme: values.get(APPEARANCE.cookies.theme),
    accent: values.get(APPEARANCE.cookies.accent),
  });
}

// WCAG 2.x relative luminance; the constants are the sRGB transfer curve from the standard.
function channel(value: number): number {
  const c = value / 255;
  return c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4;
}

function luminance(hex: string): number {
  const n = Number.parseInt(hex.slice(1), 16);
  return 0.2126 * channel((n >> 16) & 255) + 0.7152 * channel((n >> 8) & 255) + 0.0722 * channel(n & 255);
}

export function contrastRatio(a: string, b: string): number {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x) as [number, number];
  return (hi + 0.05) / (lo + 0.05);
}

const NOT_LIGHT = ':root:not([data-theme="light"])';
const FORCED_DARK = ':root[data-theme="dark"]';
const otherAccents = ACCENTS.filter((accent) => accent !== APPEARANCE.defaults.accent);

function baseVars(mode: ColorMode): string {
  const { background, foreground } = APPEARANCE.base[mode];
  return `color-scheme:${mode};--background:${background};--foreground:${foreground};`;
}

function accentVars(accent: Accent, mode: ColorMode): string {
  const { accent: fill, onAccent } = APPEARANCE.accents[accent][mode];
  return `--accent:${fill};--on-accent:${onAccent};--accent-text:${fill};`;
}

function modeRules(root: string, mode: ColorMode): string {
  return [
    `${root}{${baseVars(mode)}${accentVars(APPEARANCE.defaults.accent, mode)}}`,
    ...otherAccents.map((accent) => `${root}[data-accent="${accent}"]{${accentVars(accent, mode)}}`),
  ].join("");
}

// Order carries the cascade: system dark overrides light, a forced dark comes last, and an accent
// selector is one attribute more specific than its theme's base rule.
export function appearanceCss(): string {
  return `${modeRules(":root", "light")}@media (prefers-color-scheme: dark){${modeRules(NOT_LIGHT, "dark")}}${modeRules(FORCED_DARK, "dark")}`;
}

// Runs in <head> before the first paint (Next 16 "Preventing flash before hydration"): the root
// layout cannot read cookies without making every screen request-time under cacheComponents.
// Only listed values reach setAttribute, so a forged cookie cannot inject anything.
export function appearanceScript(): string {
  const themes = JSON.stringify(THEMES.filter((theme) => theme !== APPEARANCE.defaults.theme));
  const accents = JSON.stringify(otherAccents);
  const { theme, accent } = APPEARANCE.cookies;
  return `(function(){try{var d=document.documentElement,c="; "+document.cookie;function g(n){var p=c.split("; "+n+"=");return p.length>1?p[1].split(";")[0]:null}var t=g(${JSON.stringify(theme)}),a=g(${JSON.stringify(accent)});if(${themes}.indexOf(t)>=0)d.setAttribute("data-theme",t);if(${accents}.indexOf(a)>=0)d.setAttribute("data-accent",a)}catch(e){}})()`;
}

type AttributeTarget = {
  setAttribute(name: string, value: string): void;
  removeAttribute(name: string): void;
};

export function applyAppearance(root: AttributeTarget, { theme, accent }: Appearance): void {
  if (theme === APPEARANCE.defaults.theme) root.removeAttribute("data-theme");
  else root.setAttribute("data-theme", theme);
  if (accent === APPEARANCE.defaults.accent) root.removeAttribute("data-accent");
  else root.setAttribute("data-accent", accent);
}

export function themeColorFor(theme: Theme, media: string): string {
  const mode: ColorMode =
    theme === "system" ? (media.includes("dark") ? "dark" : "light") : theme;
  return APPEARANCE.base[mode].background;
}

type MetaLike = { getAttribute(name: string): string | null; setAttribute(name: string, value: string): void };

// The phone's status bar takes theme-color; the metas carry system media queries, so a forced theme
// rewrites both to its own color.
export function syncThemeColor(doc: { querySelectorAll(selector: string): Iterable<MetaLike> }, theme: Theme): void {
  for (const meta of doc.querySelectorAll('meta[name="theme-color"]')) {
    meta.setAttribute("content", themeColorFor(theme, meta.getAttribute("media") ?? ""));
  }
}

export function themeColorViewport(): { media: string; color: string }[] {
  return (["light", "dark"] as const).map((mode) => ({
    media: `(prefers-color-scheme: ${mode})`,
    color: APPEARANCE.base[mode].background,
  }));
}
```

```ts
import { describe, expect, it } from "vitest";
import { PWA } from "@/lib/config";
import { serviceWorkerSource } from "./service-worker";

type Listener = (event: Record<string, unknown>) => void;

function loadWorker(network: (request: { url: string }) => Promise<Response>) {
  const listeners: Record<string, Listener> = {};
  const stored = new Map<string, Response>();
  const deleted: string[] = [];
  const caches = {
    open: async () => ({
      addAll: async (urls: string[]) => urls.forEach((url) => stored.set(url, new Response(`cached ${url}`))),
    }),
    match: async (url: string) => stored.get(url),
    keys: async () => ["bitewise-v0", PWA.cacheName],
    delete: async (key: string) => (deleted.push(key), true),
  };
  const self = {
    addEventListener: (type: string, listener: Listener) => (listeners[type] = listener),
    skipWaiting: async () => undefined,
    clients: { claim: async () => undefined },
  };
  new Function("self", "caches", "fetch", "Response", serviceWorkerSource())(self, caches, network, Response);
  return { listeners, stored, deleted };
}

async function dispatch(listener: Listener, fields: Record<string, unknown> = {}) {
  let waited: Promise<unknown> | undefined;
  let responded: Promise<Response> | undefined;
  listener({ ...fields, waitUntil: (p: Promise<unknown>) => (waited = p), respondWith: (p: Promise<Response>) => (responded = p) });
  await waited;
  return responded;
}

const offline = () => Promise.reject(new TypeError("Failed to fetch"));

describe("service worker", () => {
  it("caches the offline page on install", async () => {
    const worker = loadWorker(offline);
    await dispatch(worker.listeners.install!);
    expect(worker.stored.has(PWA.offlinePath)).toBe(true);
  });

  it("drops caches of older versions on activate", async () => {
    const worker = loadWorker(offline);
    await dispatch(worker.listeners.activate!);
    expect(worker.deleted).toEqual(["bitewise-v0"]);
  });

  it("answers a failed page navigation with the offline page", async () => {
    const worker = loadWorker(offline);
    await dispatch(worker.listeners.install!);
    const response = await dispatch(worker.listeners.fetch!, { request: { mode: "navigate", url: "/" } });

  it("passes a working navigation through", async () => {
    const worker = loadWorker(async () => new Response("live"));
    const response = await dispatch(worker.listeners.fetch!, { request: { mode: "navigate", url: "/" } });
    expect(await (await response!).text()).toBe("live");
  });

  it("leaves data, actions and assets alone", async () => {
```

`lib/pwa/service-worker.ts`:
```ts
import { PWA } from "@/lib/config";
import { pwaIconUrl, pwaIcons } from "./icons";

// Only page navigations are touched. Data, server actions and hashed JS/CSS go straight to the
// network: the browser caches immutable assets itself, and a second cache here is how a stale
// version outlives a deploy.
export function serviceWorkerSource(): string {
  const cacheName = JSON.stringify(PWA.cacheName);
  const offline = JSON.stringify(PWA.offlinePath);
  const precache = JSON.stringify([PWA.offlinePath, ...pwaIcons().map(pwaIconUrl)]);
  return `"use strict";
const CACHE = ${cacheName};
const OFFLINE = ${offline};
self.addEventListener("install", (event) => {
  event.waitUntil(caches.open(CACHE).then((cache) => cache.addAll(${precache})).then(() => self.skipWaiting()));
});
self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys()
      .then((keys) => Promise.all(keys.filter((key) => key !== CACHE).map((key) => caches.delete(key))))
      .then(() => self.clients.claim()),
  );
});
self.addEventListener("fetch", (event) => {
  if (event.request.mode !== "navigate") return;
  event.respondWith(fetch(event.request).catch(() => caches.match(OFFLINE).then((page) => page || Response.error())));
});
`;
}
```

```ts
export type InstallHint = "prompt" | "ios" | null;

// iPadOS asks for the desktop site and reports itself as a Mac; touch points give it away.
export function isIos(userAgent: string, maxTouchPoints: number): boolean {
  return /iPhone|iPad|iPod/.test(userAgent) || (/Macintosh/.test(userAgent) && maxTouchPoints > 1);
}

export function installHint(env: {
  standalone: boolean;
  canPrompt: boolean;
  userAgent: string;
  maxTouchPoints: number;
}): InstallHint {
  if (env.standalone) return null;
  if (env.canPrompt) return "prompt";
  return isIos(env.userAgent, env.maxTouchPoints) ? "ios" : null;
}
```

- [ ] **Шаг 5:** `lib/pwa/install-prompt.ts` (клиентский модуль):
```ts
// Chrome fires beforeinstallprompt once, often before the profile screen exists; the root layout
// catches it here and the install row reads it when it mounts.
type InstallPromptEvent = Event & { prompt(): Promise<void> };

let deferred: InstallPromptEvent | null = null;
const subscribers = new Set<() => void>();

function notify() {
  for (const subscriber of subscribers) subscriber();
}

export function listenForInstallPrompt(target: Window): () => void {
  const onPrompt = (event: Event) => {
    // Keeps the browser's own mini-bar away; the profile offers the dialog instead.
    event.preventDefault();
    deferred = event as InstallPromptEvent;
    notify();
  };
  const onInstalled = () => {
    deferred = null;
    notify();
  };
  target.addEventListener("beforeinstallprompt", onPrompt);
  target.addEventListener("appinstalled", onInstalled);
  return () => {
    target.removeEventListener("beforeinstallprompt", onPrompt);
    target.removeEventListener("appinstalled", onInstalled);
  };
}

export function subscribeInstallPrompt(subscriber: () => void): () => void {
  subscribers.add(subscriber);
  return () => subscribers.delete(subscriber);
}

export function getInstallPrompt(): InstallPromptEvent | null {
  return deferred;
}

// The event can be used once; after the dialog the row hides until the browser offers it again.
export async function promptInstall(): Promise<void> {
  const event = deferred;
  if (!event) return;
  deferred = null;
  notify();
  await event.prompt();
}
```

```tsx
"use client";

import { useEffect, useState, useSyncExternalStore } from "react";
import { ru } from "@/lib/i18n/ru";
import { installHint } from "@/lib/pwa/install";
import { getInstallPrompt, promptInstall, subscribeInstallPrompt } from "@/lib/pwa/install-prompt";

type Device = { standalone: boolean; userAgent: string; maxTouchPoints: number };

export function InstallRow() {
  const prompt = useSyncExternalStore(subscribeInstallPrompt, getInstallPrompt, () => null);
  // Read after mount: the server and the first client render must agree (both render nothing).
  const [device, setDevice] = useState<Device | null>(null);
  useEffect(() => {
    setDevice({
      standalone:
        window.matchMedia("(display-mode: standalone)").matches ||
        (navigator as Navigator & { standalone?: boolean }).standalone === true,
      userAgent: navigator.userAgent,
      maxTouchPoints: navigator.maxTouchPoints,
    });
  }, []);
  if (!device) return null;
  const hint = installHint({ ...device, canPrompt: prompt !== null });
  if (hint === "prompt") {
    return (
      <button type="button" onClick={() => void promptInstall()} className="flex min-h-11 items-center text-left text-accent-text underline">
        {ru.install.button}
      </button>
    );
  }
  if (hint === "ios") {
    return (
      <div className="flex min-h-11 flex-col justify-center py-2">
        <p>{ru.install.iosTitle}</p>
        <p className="text-sm text-foreground/60">{ru.install.iosHint}</p>
      </div>
    );
  }
  return null;
}
```
