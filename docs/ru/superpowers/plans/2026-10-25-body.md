# Вода, вес, статистика — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** вода одним тапом на главной, вес с графиком и средним за 7 дней, статистика за неделю и месяц.

**Architecture:** чистые функции (`lib/nutrition.ts` — итоги периода, `lib/body.ts` — среднее веса, `lib/chart.ts` — геометрия SVG) отдельно от ввода-вывода (`lib/water/repo.ts`, `lib/weight/repo.ts`, `lib/stats/repo.ts`); server actions по образцу дневника; графики — серверные SVG-компоненты.

**Tech Stack:** Next.js 16, Drizzle/Postgres, zod, Vitest. Новых зависимостей нет.

**Spec:** `docs/ru/superpowers/specs/2026-10-25-body-design.md`

## Global Constraints
- Ккал и БЖУ — только `lib/nutrition.ts`; хранить без округления, округлять при выводе.
- Все значения — в `lib/config.ts` (`WATER`, `WEIGHT`, `STATS`); тексты — `lib/i18n/ru.ts`; 375 px, тап-зоны ≥ 44 px, светлая и тёмная тема, цвет действия — `bg-accent`.
- Схема — через `/db-change`: SQL показать владельцу и ждать «ок» перед `pnpm db:migrate`.
- Документация — парой `docs/ru/` и `docs/en/`.

## Review Focus
1. Повтор «+250» (ответ потерян) не добавляет вторую строку; двойной тап не даёт двух записей.
2. Удаление последнего взвешивания возвращает вес профиля к предыдущему; ручная норма не меняется.
3. День без записей не входит в средние и в «M» у «дней в норме»; деление на ноль при пустом периоде.
4. Граница периода — сегодня в поясе пользователя, не UTC.
5. График с одной точкой, с одинаковыми значениями (нулевой размах) и с пропусками.

---

### Task 1: Итоги периода — `lib/nutrition.ts` (TDD)
- `calcPeriodSummary(days: { date; nutrients }[], target: Nutrients): { average: Nutrients; daysLogged; daysInTarget }`; `isDayInTarget(kcal, targetKcal)` по `STATS.inTargetShare`.
- Тесты: ручные числа, пустой период (средние 0, дней 0), граница ±10 % включительно.

### Task 2: Среднее веса — `lib/body.ts` (TDD)
- `calcWeightTrend(entries: { date; weightKg }[]): { date; weightKg; averageKg }[]` — окно `WEIGHT.averageDays` календарных дней.
- Тесты: одна точка, пропуски, неотсортированный вход.

### Task 3: Геометрия графиков — `lib/chart.ts` (TDD)
- `linearScale(domain, range)`, `paddedDomain(values, minSpan)`, `dateIndex(from, date)`.
- Тесты: нулевой размах, одна точка, обратный диапазон по Y.

### Task 4: Схема и миграция (`/db-change`)
- `water_entries`, `weight_entries` (см. спеку); `pnpm db:generate` → показать SQL → «ок» → `pnpm db:migrate`.

### Task 5: Вода

### Task 6: Вес

- `app/(app)/body/` (`page.tsx`, `[date]/page.tsx`, `actions.ts`), `components/body/` (`weight-form`, `weight-chart`, `weight-history`).

### Task 7: Статистика

- `app/(app)/stats/page.tsx`, `components/stats/` (`period-switch`, `kcal-chart`, `day-list`); ссылки «Вес» и «Статистика» на главной.
