# Этап 3 — дневник: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пользователь записывает еду по приёмам пищи (по граммам или порциям), правит и удаляет записи и видит итоги дня с прогрессом к норме; можно ходить по дням.

**Architecture:** Таблица `diary_entries` хранит снимок продукта «на 100 г», граммы и снимок порции. Все числа считают чистые функции `lib/nutrition.ts`; репозиторий `lib/diary/repo.ts` фильтрует всё по `user_id`; server actions в `app/(app)/diary/actions.ts`. «Сегодня» считается по часовому поясу из cookie `tz`, которую ставит клиентский компонент. Экраны: день на `/`, выбор продукта `/diary/add`, количество `/diary/add/[foodId]`, правка `/diary/entries/[id]/edit`.

**Tech Stack:** Next.js 16 (App Router, `cacheComponents`), React 19, TypeScript strict, Drizzle ORM + Postgres 17, zod 4, Vitest 5, Tailwind v4.

**Spec:** `docs/ru/superpowers/specs/2026-10-11-diary-design.md`

## Global Constraints
- Нутриенты считает только `lib/nutrition.ts`; клиент нутриенты не считает (ккал на порцию приходит с сервера).
- Без магических чисел: всё настраиваемое — в `lib/config.ts`.
- Комментарии в коде — по-английски, объясняют «почему». Тексты интерфейса — только из `lib/i18n/ru.ts`.
- Каждый запрос к `diary_entries` фильтрует по `user_id` сессии; чужое → «не найдено» (404).
- Схема БД — только в `db/schema.ts`, миграция через `pnpm db:generate`; сгенерированный SQL не править; `pnpm db:migrate` — после «ок» пользователя.
- Хранить и считать без округления; округлять только при выводе (`lib/format.ts`).
- Mobile-first 375 px, тап-зоны ≥ 44 px (`min-h-11`), без горизонтального скролла.
- Каждая страница — `<Suspense fallback={<PageLoading />}>` + `…Content`, сессия читается внутри.
- `DIARY_LIMITS`: граммы 0,1–5000; количество порций 0,25–50, шаг кнопок 0,5, по умолчанию 1; не больше 100 записей в день; дата от `2000-01-01` до «сегодня» пользователя.
- `DEFAULT_TIME_ZONE = "Asia/Almaty"`, cookie `tz`.
- Новых зависимостей нет.
- Коммиты — Conventional Commits по-английски, в конце `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Не пушить.

## Review Focus
- Ручная норма с 0 г углеводов (или белка) → `share` не должен стать `NaN`: 0 съедено → 0, что-то съедено → `Infinity` (полоса полная и красная). Тест — Task 1.
- Удаление пользователя, у которого в дневнике его собственные продукты: FK `food_id` (no action) не должен блокировать каскад. Тест — Task 5.
- `?date=` мусорный, массивом (`?date=a&date=b`), в будущем, до 2000 года → `null` → 404, а не падение. Тест — Task 4.
- Количество порций с лишними знаками (`0,333`) → округляется до точности столбца (0,33), иначе `grams ≠ count × portion_grams` после сохранения. Тест — Task 4.
- Мусорная или слишком длинная cookie `tz` → пояс по умолчанию, без исключения из `Intl`. Тест — Task 2.

export type Per100g = { kcal100: number; protein100: number; fat100: number; carbs100: number };

export type Nutrients = { kcal: number; proteinG: number; fatG: number; carbsG: number };

export function calcEntryNutrients(per100g: Per100g, grams: number): Nutrients {
  assertNonNegative("grams", grams);
  const scale = (valuePer100g: number) => (valuePer100g * grams) / NUTRIENT_BASE_GRAMS;
  return {
    kcal: scale(per100g.kcal100),
    proteinG: scale(per100g.protein100),
    fatG: scale(per100g.fat100),
    carbsG: scale(per100g.carbs100),
  };
}

export function calcPortionGrams(portionGrams: number, count: number): number {
  assertPositive("portionGrams", portionGrams);
  assertPositive("count", count);
  return portionGrams * count;
}

const ZERO_NUTRIENTS: Nutrients = { kcal: 0, proteinG: 0, fatG: 0, carbsG: 0 };

export function sumNutrients(list: readonly Nutrients[]): Nutrients {
  return list.reduce(
    (total, item) => ({
      kcal: total.kcal + item.kcal,
      proteinG: total.proteinG + item.proteinG,
      fatG: total.fatG + item.fatG,
      carbsG: total.carbsG + item.carbsG,
    }),
    ZERO_NUTRIENTS,
  );
}

export type NutrientProgress = { eaten: number; target: number; remaining: number; share: number };

export type DayProgress = Record<keyof Nutrients, NutrientProgress>;

function calcNutrientProgress(target: number, eaten: number): NutrientProgress {
  assertNonNegative("target", target);
  assertNonNegative("eaten", eaten);
  // A manual target may set a macro to 0 g; anything eaten then is fully "over", never NaN.
  const share = target > 0 ? eaten / target : eaten > 0 ? Infinity : 0;
  return { eaten, target, remaining: target - eaten, share };
}

export function calcDayProgress(target: Nutrients, eaten: Nutrients): DayProgress {
  return {
    kcal: calcNutrientProgress(target.kcal, eaten.kcal),
    proteinG: calcNutrientProgress(target.proteinG, eaten.proteinG),
    fatG: calcNutrientProgress(target.fatG, eaten.fatG),
    carbsG: calcNutrientProgress(target.carbsG, eaten.carbsG),
  };
}
```

// Intl is the only zone-aware calendar in Node; formatToParts avoids relying on a locale's layout.
export function todayInTimeZone(now: Date, timeZone: string): IsoDate {
  const parts = new Intl.DateTimeFormat("en-US", {
    timeZone,
    year: "numeric",
    month: "2-digit",
    day: "2-digit",
  }).formatToParts(now);
  const part = (type: Intl.DateTimeFormatPartTypes) =>
    parts.find((item) => item.type === type)?.value ?? "";
  return `${part("year")}-${part("month")}-${part("day")}`;
}

// Calendar arithmetic in UTC: no zone means no daylight-saving hour to skip a day over.
export function addDays(date: IsoDate, days: number): IsoDate {
  const parsed = parseIsoDate(date);
  if (!parsed) throw new RangeError(`invalid date: ${date}`);
  const shifted = new Date(Date.UTC(parsed.year, parsed.month - 1, parsed.day + days));
  return shifted.toISOString().slice(0, 10);
}

export function isValidTimeZone(value: string): boolean {
  if (!value) return false;
  try {
    new Intl.DateTimeFormat("en-US", { timeZone: value });
    return true;
  } catch {
    return false;
  }
}
```

// The cookie is client-controlled: anything that is not a real IANA zone gets the default.
export function resolveTimeZone(raw: string | undefined): string {
  if (!raw || raw.length > TIME_ZONE_COOKIE.maxLength) return DEFAULT_TIME_ZONE;

import { NUTRIENT_STORAGE_DECIMALS } from "@/lib/config";
import { addDays, parseIsoDate, type IsoDate } from "@/lib/date";
import { ru } from "@/lib/i18n/ru";

// Rounding lives only here: stored and computed values keep full precision.
export function formatKcal(kcal: number): string {
  return String(Math.round(kcal));
}

export function formatGrams(grams: number): string {
  return String(Math.round(grams));
}

const amountFormat = new Intl.NumberFormat(ru.locale, {
  maximumFractionDigits: NUTRIENT_STORAGE_DECIMALS,
  useGrouping: false,
});

// Portion counts are stored to hundredths, so that is all the precision worth showing.
export function formatAmount(count: number): string {
  return amountFormat.format(count);
}

export function formatDayLabel(date: IsoDate, today: IsoDate): string {
  if (date === today) return ru.diary.today;
  if (date === addDays(today, -1)) return ru.diary.yesterday;
  const parsed = parseIsoDate(date);
  if (!parsed) throw new RangeError(`invalid date: ${date}`);
  const weekdayIndex = new Date(Date.UTC(parsed.year, parsed.month - 1, parsed.day)).getUTCDay();
  const month = ru.diary.monthsShort[parsed.month - 1];
  const weekday = ru.diary.weekdaysShort[weekdayIndex];
  if (month === undefined || weekday === undefined) {
    throw new RangeError(`invalid date: ${date}`);
  }
  const sameYear = parseIsoDate(today)?.year === parsed.year;
  return ru.diary.dayLabel(parsed.day, month, weekday, sameYear ? undefined : parsed.year);
}

export function formatEntryAmount(entry: {
  grams: number;
  portionLabel: string | null;
  portionCount: number | null;
}): string {
  const grams = formatGrams(entry.grams);
  if (entry.portionLabel === null || entry.portionCount === null) {
    return ru.diary.amountGrams(grams);
  }
  return entry.portionCount === 1
    ? ru.diary.amountPortion(entry.portionLabel, grams)
    : ru.diary.amountPortions(formatAmount(entry.portionCount), entry.portionLabel, grams);
}

```ts
import { z } from "zod";
import { DIARY_LIMITS, MEALS, NUTRIENT_STORAGE_DECIMALS, type Meal } from "@/lib/config";
import { parseIsoDate, type IsoDate } from "@/lib/date";
import { decimalField } from "@/lib/forms";
import { ru } from "@/lib/i18n/ru";
import type { AddAmount, UpdateAmount } from "./types";

const STORAGE_SCALE = 10 ** NUTRIENT_STORAGE_DECIMALS;
// Inputs get the precision the columns store, so grams = count × portion grams holds once saved.
const toStoragePrecision = (value: number) => Math.round(value * STORAGE_SCALE) / STORAGE_SCALE;

const { grams, portionCount } = DIARY_LIMITS;
const gramsField = () =>
  decimalField(grams, ru.errors.gramsRange(grams.min, grams.max)).transform(toStoragePrecision);
const countField = () =>
  decimalField(portionCount, ru.errors.portionCount(portionCount.min, portionCount.max)).transform(
    toStoragePrecision,
  );

export const mealSchema = z.enum(MEALS, { error: ru.errors.choose });

const gramsAmountSchema = z.object({ mode: z.literal("grams"), grams: gramsField() });

// Forms post flat fields; the intersection keeps every error on its own field name.
export const addEntryFormSchema = z.object({ meal: mealSchema }).and(
  z.discriminatedUnion("mode", [
    gramsAmountSchema,
    z.object({
      mode: z.literal("portion"),
      portionId: z.uuid({ error: ru.errors.choosePortion }),
      count: countField(),
    }),
  ]),
);

export const updateEntryFormSchema = z
  .object({ meal: mealSchema })
  .and(
    z.discriminatedUnion("mode", [
      gramsAmountSchema,
      z.object({ mode: z.literal("portion"), count: countField() }),
    ]),
  );

export type AddEntryForm = z.infer<typeof addEntryFormSchema>;
export type UpdateEntryForm = z.infer<typeof updateEntryFormSchema>;

export function toAddAmount(form: AddEntryForm): AddAmount {
  return form.mode === "grams"
    ? { mode: "grams", grams: form.grams }
    : { mode: "portion", portionId: form.portionId, count: form.count };
}

export function toUpdateAmount(form: UpdateEntryForm): UpdateAmount {
  return form.mode === "grams"
    ? { mode: "grams", grams: form.grams }
    : { mode: "portion", count: form.count };
}

// Dates arrive from URLs and hidden fields; the future is not a diary day.
export function parseDiaryDate(value: unknown, today: IsoDate): IsoDate | null {
  if (typeof value !== "string" || !parseIsoDate(value)) return null;
  // ISO dates compare correctly as plain strings.
  return value >= DIARY_LIMITS.minDate && value <= today ? value : null;
}

export function parseMeal(value: unknown): Meal | null {
  const parsed = mealSchema.safeParse(value);
  return parsed.success ? parsed.data : null;
}

const idSchema = z.uuid();

// Postgres throws on a malformed uuid, so ids from URLs and bound arguments are checked first.
export function parseId(value: unknown): string | null {
  const parsed = idSchema.safeParse(value);
  return parsed.success ? parsed.data : null;
}
```

// A portion is usable only through a food the user sees and only if it belongs to that food.
export async function getVisiblePortion(
  db: Db,
  userId: string,
  foodId: string,
  portionId: string,
): Promise<PortionValues | null> {
  const [row] = await db
    .select({ label: foodPortions.label, grams: foodPortions.grams })
    .from(foodPortions)
    .innerJoin(foods, eq(foods.id, foodPortions.foodId))
    .where(
      and(
        eq(foodPortions.id, portionId),
        eq(foodPortions.foodId, foodId),
        visibleTo(userId),
        or(isNull(foodPortions.userId), eq(foodPortions.userId, userId)),
      ),
    )
    .limit(1);
  return row ?? null;
}

import { and, asc, count, eq, sql } from "drizzle-orm";
import { diaryEntries, foods } from "@/db/schema";
import type { Db } from "@/db/types";
import { DIARY_LIMITS } from "@/lib/config";
import type { IsoDate } from "@/lib/date";

import type { PortionValues } from "@/lib/foods/types";
import { calcPortionGrams } from "@/lib/nutrition";
import type { AddAmount, AddEntryInput, DiaryEntry, UpdateEntryInput } from "./types";

const entryColumns = {
  id: diaryEntries.id,
  date: diaryEntries.date,
  meal: diaryEntries.meal,
  foodName: diaryEntries.foodName,
  kcal100: diaryEntries.kcal100,
  protein100: diaryEntries.protein100,
  fat100: diaryEntries.fat100,
  carbs100: diaryEntries.carbs100,
  grams: diaryEntries.grams,
  portionLabel: diaryEntries.portionLabel,
  portionGrams: diaryEntries.portionGrams,
  portionCount: diaryEntries.portionCount,
};

function ownEntry(userId: string, entryId: string) {
  return and(eq(diaryEntries.id, entryId), eq(diaryEntries.userId, userId));
}

const NO_PORTION = { portionLabel: null, portionGrams: null, portionCount: null };

export async function getDayEntries(db: Db, userId: string, date: IsoDate): Promise<DiaryEntry[]> {
  return (
    db
      .select(entryColumns)
      .from(diaryEntries)
      .where(and(eq(diaryEntries.userId, userId), eq(diaryEntries.date, date)))
      // Enum columns sort in declaration order, which is the order of meals in a day.
      .orderBy(asc(diaryEntries.meal), asc(diaryEntries.createdAt), asc(diaryEntries.id))
  );
}

export async function getEntry(
  db: Db,
  userId: string,
  entryId: string,
): Promise<DiaryEntry | null> {
  const [row] = await db
    .select(entryColumns)
    .from(diaryEntries)
    .where(ownEntry(userId, entryId))
    .limit(1);
  return row ?? null;
}

function amountColumns(amount: AddAmount, portion: PortionValues | null) {
  if (amount.mode === "grams") return { grams: amount.grams, ...NO_PORTION };
  // addEntry returns "not_found" before calling this without a portion.
  if (!portion) throw new Error("portion amount without a portion");
  return {
    grams: calcPortionGrams(portion.grams, amount.count),
    portionLabel: portion.label,
    portionGrams: portion.grams,
    portionCount: amount.count,
  };
}

export async function addEntry(
  db: Db,
  userId: string,
  input: AddEntryInput,
): Promise<"ok" | "not_found" | "limit"> {
  return db.transaction(async (tx) => {
    const [food] = await tx
      .select({
        name: foods.name,
        kcal100: foods.kcal100,
        protein100: foods.protein100,
        fat100: foods.fat100,
        carbs100: foods.carbs100,
      })
      .from(foods)
      .where(and(eq(foods.id, input.foodId), visibleTo(userId)))
      .limit(1);
    if (!food) return "not_found";
    const { amount } = input;
    let portion: PortionValues | null = null;
    if (amount.mode === "portion") {
      portion = await getVisiblePortion(tx, userId, input.foodId, amount.portionId);
      if (!portion) return "not_found";
    }
    // Two simultaneous submits can overshoot by one; the cap bounds scripts, not people.
    const [day] = await tx
      .select({ total: count() })
      .from(diaryEntries)
      .where(and(eq(diaryEntries.userId, userId), eq(diaryEntries.date, input.date)));
    if ((day?.total ?? 0) >= DIARY_LIMITS.maxEntriesPerDay) return "limit";
    await tx.insert(diaryEntries).values({
      userId,
      date: input.date,
      meal: input.meal,
      foodId: input.foodId,
      foodName: food.name,
      kcal100: food.kcal100,
      protein100: food.protein100,
      fat100: food.fat100,
      carbs100: food.carbs100,
      ...amountColumns(amount, portion),
    });
    return "ok";
  });
}

export async function updateEntry(
  db: Db,
  userId: string,
  entryId: string,
  input: UpdateEntryInput,
): Promise<{ date: IsoDate } | null> {
  return db.transaction(async (tx) => {
    const [entry] = await tx
      .select({ date: diaryEntries.date, portionGrams: diaryEntries.portionGrams })
      .from(diaryEntries)
      .where(ownEntry(userId, entryId))
      .limit(1);
    if (!entry) return null;
    const { amount } = input;
    let columns: Partial<typeof diaryEntries.$inferInsert>;
    if (amount.mode === "grams") {
      columns = { grams: amount.grams, ...NO_PORTION };
    } else {
      // Only the snapshotted portion can be counted; a grams entry has none to count.
      if (entry.portionGrams === null) return null;
      columns = {
        grams: calcPortionGrams(entry.portionGrams, amount.count),
        portionCount: amount.count,
      };
    }
    await tx
      .update(diaryEntries)
      .set({ meal: input.meal, ...columns, updatedAt: sql`now()` })
      .where(ownEntry(userId, entryId));
    return { date: entry.date };
  });
}

export async function deleteEntry(
  db: Db,
  userId: string,
  entryId: string,
): Promise<{ date: IsoDate } | null> {
  const [row] = await db
    .delete(diaryEntries)
    .where(ownEntry(userId, entryId))
    .returning({ date: diaryEntries.date });
  return row ?? null;
}

"use client";

import { useRouter } from "next/navigation";
import { useEffect } from "react";
import { TIME_ZONE_COOKIE } from "@/lib/config";

// The server cannot know the device's zone, so the browser reports it once and re-renders.
// IANA names hold only letters, digits, "_", "+", "-" and "/", all valid in a cookie value.
export function TimeZoneCookie() {
  const router = useRouter();
  useEffect(() => {
    const zone = Intl.DateTimeFormat().resolvedOptions().timeZone;
    const prefix = `${TIME_ZONE_COOKIE.name}=`;
    const current = document.cookie
      .split("; ")
      .find((item) => item.startsWith(prefix))
      ?.slice(prefix.length);
    if (current === zone) return;
    const secure = window.location.protocol === "https:" ? "; secure" : "";
    document.cookie = `${prefix}${zone}; path=/; max-age=${TIME_ZONE_COOKIE.maxAgeSec}; samesite=lax${secure}`;
    router.refresh();
  }, [router]);
  return null;
}

// Bound arguments and hidden fields come from the client and can be tampered with.
function requireId(value: unknown): string {
  const id = parseId(value);
  if (!id) notFound();
  return id;

export async function addEntryAction(_prev: FormState, formData: FormData): Promise<FormState> {
  const userId = await requireUserId();
  const today = await getUserToday(new Date());
  const raw = Object.fromEntries(formData);
  const date = parseDiaryDate(raw.date, today);
  if (!date) notFound();
  const foodId = requireId(raw.foodId);
  const parsed = addEntryFormSchema.safeParse(raw);
  if (!parsed.success) return { fieldErrors: firstFieldErrors(parsed.error) };
  const result = await addEntry(db, userId, {
    date,
    meal: parsed.data.meal,
    foodId,
    amount: toAddAmount(parsed.data),
  });
  if (result === "not_found") notFound();
  if (result === "limit") return { formError: ru.diary.entryLimit(DIARY_LIMITS.maxEntriesPerDay) };
  redirect(dayHref(date, today));
}

export async function updateEntryAction(
  entryId: string,
  _prev: FormState,
  formData: FormData,

    meal: parsed.data.meal,
    amount: toUpdateAmount(parsed.data),

}

import { ConfirmDeleteButton } from "@/components/ui/confirm-delete-button";

import { getUserToday } from "@/lib/diary/today";

async function EditEntryContent({ params }: Pick<PageProps<"/diary/entries/[id]/edit">, "params">) {
